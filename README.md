Modified versions of the codes 'get_spectra_using_CF' and 'finite', 
which are a part of the program impurityModel originally written by Johan Schött, are seen in this repository. 
The original versions are found using the link: https://github.com/JohanSchott/impurityModel/. 

The modified versions were created as part of my Bachelor's thesis, and computes the linear entropy of a system consisting of localized 4f-electrons and delocalized 5d-electrons.
